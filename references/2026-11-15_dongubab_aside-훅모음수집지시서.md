# aside 주간 수집 지시서 — 훅 모음 갱신

작성일: 2026-11-15 / 주기: 주 1회(권장 일요일) / 적재: `python3 scripts/hookbank.py add --views <조회.csv> --top <상위.csv> --date YYYY-MM-DD`
목적: 업종을 말하면 reels-auto가 요즘 잘된 영상의 형식을 자동으로 참고하도록 `references/hookbank.csv`를 최신으로 유지.

## aside 지시문 (그대로 복사)
```
[공통 규칙] 읽기만, 다운로드 금지, 없는 값은 빈칸, 숫자는 화면 표기 그대로.

[1. 업종별 인기 릴스]
아래 해시태그마다 "인기 게시물"에서 릴스만 상위 5개:
#분당빵집 #빵지순례 #서울술집 #을지로술집 #노포맛집 #서울노포 #샤브샤브맛집 #강남맛집 #서울카페 #판교카페
게시물마다 한 줄 → 상위.csv
헤더: 계정,태그,세부,지역,게시물URL,게시일,공개 조회수,커버 1줄,커버 2줄,첫 3초 화면,영상 길이(초),캡션 첫 줄,캡션 말투,협찬 표기
- 태그: 해시태그가 속한 업종 태그(빵집·디저트 / 술집 / 노포 / 한식;샤브샤브 / 카페)
- 세부: 가게 종류 한 단어(예: 소금빵집, 이자카야)
- 최근 30일 안에 올라온 것만

[2. 계정 기준 조회수]
1번에 나온 계정마다 프로필 릴스 탭의 최근 릴스 12개 공개 조회수 → 조회.csv
헤더: 계정,순번,게시물URL,공개조회수,고정여부
- 고정 게시물은 고정여부에 "고정"이라고 적고 순번에서 제외
```
