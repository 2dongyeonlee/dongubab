# sponsor-check — 협찬 가이드 체크

먼저 읽기: `../account-identity/references/rules.md`(협찬 9~12), `../account-identity/references/brands.md`

## 모드
| 모드 | 입력 | 산출 |
|---|---|---|
| 가이드 정리 | 가이드 원문·DM | 필수/금지/위치 지정/확인 필요 표 + brands.md 추가안 |
| 산출물 검사 | 가이드 + 커버·자막·캡션 | 항목별 반영 여부 체크리스트 |

## 가이드 정리 절차
1. 원문에서 아래를 그대로 뽑는다(요약·바꿔쓰기 금지): 필수 문구, 필수 해시태그·계정 태그, 광고 표기 방식·위치, 금지 표현, 게시 기간·일정, 필수 촬영 컷(주차 등)
2. 원문에 없는데 필요한 것은 "확인 필요" 질문으로 만든다(예: 유료 파트너십 라벨 사용 여부)
3. 공통 금지어(할인, 최저가, 효능)와 충돌하는 필수 문구가 있으면 표시한다
4. brands.md 추가안을 템플릿 형식으로 출력한다. 파일 수정은 동연 확인 후

## 산출물 검사 절차
| 항목 | 기준 | 결과(반영/미반영/확인 필요) | 위치 |
|---|---|---|---|
| 광고 표기 | brands.md 위치 | | |
| 필수 문구 | 단어 그대로 | | |
| 필수 태그 | 맨 아래 별도 줄 | | |
| 금지 표현 | 0건 | | |
| 훅 광고 냄새 | 커버·첫 줄에 브랜드 홍보 문구 없음 | | |
| 필수 컷(자막) | 컷 3~5 배치 | | |

- 사용자가 필수 문구 위치를 옮긴 경우: "수정 요청 리스크: 가이드 지정 위치(○○)와 다름" 한 줄 고지
- 마지막에 `python3 scripts/lint_copy.py --sponsor <파일>` 결과를 붙인다
