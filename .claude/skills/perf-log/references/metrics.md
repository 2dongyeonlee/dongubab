# perf-log 지표 정의

## 입력 필드
| 필드 | 설명 | 비고 |
|---|---|---|
| 게시일 | YYYY-MM-DD | |
| 가게 | 상호 | |
| 카테고리 | 노포 / 숨은맛집 / 대중맛집 / 바·술집 / 브랜드·팝업 / 카페·디저트 / 기타 | 하나만. 브랜드·팝업 = 백화점 팝업·프랜차이즈 지점·브랜드 매장 |
| 협찬 | Y / N | 카테고리와 별개 |
| 커버 문구 | 커버 텍스트 원문 | 줄바꿈은 " / " |
| 커버 유형 | 가격·룰 / 궁금증(정체숨김) / 구성놀람 / 공간반전 / 신상·소식 / 권위차용 / 비유·최상급 / 혜택·이벤트 / 일반워딩 / 기타 | 하나만, 가장 앞에 오는 훅 기준. 커버 이미지에 박힌 글자로 판정(캡션 아님) |
| 톤 | 반말혼잣말 / 존댓말구어체 / 기타 | 캡션·자막 기준 |
| 조회, 도달, 좋아요, 댓글, 공유, 저장, 팔로우 | 인사이트 값 | 공유에 DM 공유가 포함되는지는 인사이트 화면 기준으로 확인 필요 |
| 평균 시청(초) | 인사이트 "평균 시청 시간" | |
| 건너뛰기율 | 0~1 (예: 58.9% → 0.589) | 없으면 빈칸 |
| 비팔로워비율 | 인사이트 "조회수" 아래 "팔로워가 아닌 사람" %, 0~1 | 노출 확산 지표(핵심) |
| 도달 | 인사이트 "조회한 사람" | 조회 대비 비정상(예: 조회 6.5만에 172)이면 비우고 메모 |
| 메모 | 판독 불확실 값, 특이사항 | |

## 계산 열 (xlsx 수식, 도달이 비면 빈칸)
| 열 | 수식 |
|---|---|
| 공유율 | 공유 / 도달 |
| 저장율 | 저장 / 도달 |
| 팔로우율 | 팔로우 / 도달 |
| 공유/저장 | 공유 / 저장 (≥1 소환형, <1 위시리스트형) |
| 유형 | IF(공유/저장 ≥ 1, "소환형", "위시리스트형") |
| 공유/조회, 저장/조회, 팔로우/조회 | 도달이 비거나 의심일 때 비교 기준. v2 시트의 x/좋아요 대체지표는 폐기 |

## 요약 시트
- 카테고리별·커버 유형별·협찬 여부별 게시물 수와 평균(공유율, 저장율, 팔로우율, 평균 시청)을 AVERAGEIFS·COUNTIFS로 계산한다.
- 표본이 3개 미만인 그룹은 리포트에서 "표본 부족"으로 표기한다.

## 입력 경로
- aside 수집 CSV → `log/YYYY-MM-DD_dongubab_aside수집_정규화.csv`(카테고리·톤은 Claude가 분류, 메모에 근거) → `python3 scripts/make_perf_sheet.py <out_vN.xlsx> <정규화.csv>`
