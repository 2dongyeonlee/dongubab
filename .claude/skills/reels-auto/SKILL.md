# reels-auto — 한 번에 기획

먼저 읽기: `../account-identity/SKILL.md`, `../account-identity/references/rules.md`, 협찬이면 `../account-identity/references/brands.md`
이 스킬은 reels-cover-title → reels-subtitles → reels-caption → sponsor-check를 순서대로 실행한다. 각 스킬의 규칙을 따른다.

## 원칙
- **묻지 않고 먼저 낸다.** 빠진 정보는 [확인 필요]로 두고 진행. 보강 질문은 맨 끝에 최대 3개.
- **파일을 저장하지 않는다.** 결과는 채팅으로만. 작업용 파일은 `.reels-tmp/`(git 제외)에만 쓴다.
- 동연 경험과 남의 리뷰를 섞지 않는다. 리뷰 내용은 "리뷰상"으로만, 맛 평가는 동연이 말한 것만.

## 절차
1. **입력 파악**: 상호, 사진, 먹은 것과 한 줄 감상, 협찬 여부·가이드, 특이점(가격·품절 시간·이 집만의 메뉴), 찍은 컷.
2. **사실 수집** → `.reels-tmp/facts.txt`에 출처 태그를 붙여 쓴다.
   - [사진] 간판·메뉴판·가격표·플레이스 화면에서 읽은 것
   - [웹] 상호+지역 웹 검색 1~2회(출처 URL). 네이버 플레이스 링크는 이 환경에서 열리지 않으니 캡처를 요청한다.
   - [동연] 직접 말한 것 / [리뷰] 남의 리뷰 / [업체] 업체 소개
3. **레퍼런스**: 업종 키워드 2~3개로 `python3 scripts/hookbank.py query <키워드…> --n 3`.
   - 일치하는 레퍼런스의 **형식**(커버 구조·훅 유형·첫 3초·길이)만 참고한다. 문구는 가져오지 않는다.
   - "같은가게검색" 행이 있으면 그 훅은 쓰지 않는다.
   - 일치 0개면 "이 업종 레퍼런스 없음 → aside 주간 수집에 추가"라고 적는다.
   - 최신 수집일이 14일보다 오래됐으면 "트렌드 캡처 보내주면 갱신"이라고 적는다.
   - 같은 메시지에 트렌드 캡처(다른 계정 릴스·해시태그 화면)가 있으면 reference-analyze의 캡처 절차로 먼저 훅 모음에 넣고 조회한다.
4. **게이트(경고 모드)**: 가격·양 / 희소성 / 이 집만의 것 중 확인된 게 없으면 맨 위에 "⚠️ 킬러 소재 약함"을 띄우고 그대로 진행한다.
5. **커버 3안 + 추천**(reels-cover-title): 소환 테스트·답 검사 포함. 추천 이유에 참고한 레퍼런스를 한 줄 적는다.
6. **6컷 자막 1세트**(추천 커버용, reels-subtitles). 컷 1은 레퍼런스 첫 3초 형식(손 동작 클로즈업 등)을 반영한다.
7. **캡션**: 짧은 반말형(reels-caption). 협찬 가이드가 정보형을 요구하면 정보형.
8. **협찬 체크**: 협찬이면 sponsor-check 산출물 검사 표. 가이드가 없으면 업체에 물을 질문 목록.
9. **검사**: 커버·자막·캡션을 `.reels-tmp/copy.txt`에 쓰고 `python3 scripts/lint_copy.py .reels-tmp/copy.txt --facts .reels-tmp/facts.txt`(협찬이면 `--sponsor`)를 실행한다. 위반이 있으면 고치고 다시 검사(최대 2회).

## 출력 순서 (채팅)
1. ⚠️ 경고(있을 때만)
2. 사실 요약(출처 태그, 5줄 이내)
3. 참고 레퍼런스(최대 3개: 계정, 배수, 커버, 가져올 형식)
4. 커버 3안 표 + 추천과 소환 테스트 문장
5. 6컷 자막 표
6. 캡션(코드블록)
7. 협찬 체크(협찬일 때)
8. 검사 결과 한 줄(위반 N건 / 확인 필요 N건)
9. 보강하면 좋아지는 것(최대 3개 질문)
