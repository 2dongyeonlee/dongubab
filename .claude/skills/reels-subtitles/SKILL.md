# reels-subtitles — 6컷 자막 세트

먼저 읽기: `../account-identity/SKILL.md`, `../account-identity/references/rules.md`

## 입력
- 확정 커버(없으면 reels-cover-title 먼저), 메뉴·구성, 촬영한 컷 설명(있으면), 협찬 가이드(있으면)

## 규칙
- 6컷 × 컷당 2~4초 = 15~24초. 타임코드를 붙인다(00:00~00:03 형식).
- 컷 1(0~3초): 커버의 킬러 소재를 그대로 보여주는 장면 + 반전 한 마디. 손 동작 음식 클로즈업 권장(레퍼런스 상위 영상 9/10).
- 상호는 컷 2~4에서 공개한다(커버에는 없음).
- 컷당 자막 한 줄 15자 안팎. 반말 혼잣말.
- 협찬 필수 요소(주차, 메뉴명 등)는 컷 3~5에 배치. 컷 1에는 넣지 않는다.
- 먹지 않은 메뉴는 맛 평가 대신 구성·모양만. 불확실하면 [확인 필요].

## 흐름 (요청 시 여러 개, 기본 2개)
| 흐름 | 컷 순서 예 |
|---|---|
| 구성 흐름 | 킬러 구성 → 전체 상차림 → 메뉴 하나씩 → 마무리 |
| 주차·실용 | 킬러 소재 → 위치·주차 → 메뉴 → 팁(시간대 등) |
| 정체 공개 | 정체 숨김 컷 → 힌트 → 상호 공개 → 대표 메뉴 |
| 데이트·분위기 | 공간 반전 → 분위기 → 메뉴 → 같이 갈 사람 소환 |
| 상차림 놀람 | 상차림 전체 → 개수·구성 → 가격 |
| 먹는 순서 | 첫 입 → 두 번째 → 사리·볶음밥 → 마무리 |

## 출력 형식 (세트마다)
```
### 세트 ○: ○○ 흐름
| 컷 | 타임코드 | 화면 | 자막 |
확인 필요: ...
```
마지막에 `python3 scripts/lint_copy.py`로 자막 문구를 검사한다.
