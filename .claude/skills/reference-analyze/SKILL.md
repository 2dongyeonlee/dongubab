# reference-analyze — 레퍼런스 패턴 표

## 원칙
- 수치는 "타 계정 게시물에 표시된 값"으로만 다룬다. 내 규칙의 숫자 기준선으로 쓰지 않는다.
- 차용하는 것은 **형식**(커버 구조·줄 수·유형, 첫 3초, 길이, 시리즈 등)이고, **정체성**(소재·톤·시선)은 account-identity를 따른다.
- 스크래핑·외부 API는 이 스킬에서 실행하지 않는다. 입력은 동연이 준 캡처나 aside 수집 결과. 자동 수집은 [검토중].

## 입력 (계정마다)
- 최근 릴스 30개의 공개 조회수(고정 게시물은 따로 표시)
- 상위 N개: 게시일, 조회, 좋아요, 댓글, 커버 1~2줄, 첫 3초 화면, 길이(초), 캡션 첫 줄, 말투, 협찬 표기
- 프로필: 팔로워, 게시물 수, 소개글, 하이라이트

## 절차
1. 계정별 최근 30개 조회 **중앙값**을 구하고, 상위 영상의 배수(조회 ÷ 중앙값)를 계산한다. 고정 게시물은 제외. 계산은 스크립트로 한다.
2. 배수 2배 이상을 "잘된 영상"으로 본다(임시 기준, 데이터 보고 조정).
3. 잘된 영상마다 분석 항목(head-of-content 훅 분석 구조 참고):
   - 훅 유형(가격·룰 / 구성놀람 / 신상·소식 / 비유·최상급 / 정보격차 / 호명·소환 / 리스트·코스 / POV)
   - 커버 줄 수·줄당 글자 수(공백 제외)·지역명·숫자·상호 유무
   - 첫 3초 화면, 영상 길이, 캡션 첫 줄 유형, 말투, 협찬 표기
   - 따라 쓸 수 있는 공식 1줄(예: "[지역] / [대상]이 [가격]")
4. 패턴 표: 항목별 빈도(n/N)
5. **차용 vs 비차용 표**: 차용할 형식 / 차용하지 않을 것(정체성 충돌, 계정 규모 차이, 표기 방식 등)과 이유
6. 내 계정 히트·최근 영상과 같은 항목으로 비교(성과기록 최신 xlsx 참조)

## 출력
`references/YYYY-MM-DD_dongubab_레퍼런스분석_vN.md` (기존 파일은 덮어쓰지 않음)
- 계정 비교표(팔로워, 조회 중앙값, 중앙값/팔로워, 정체성, 말투)
- 잘된 영상 표, 패턴 표, 차용 vs 비차용 표, 다음 실험 제안 1~3개

예시: `references/2026-11-15_dongubab_레퍼런스분석_v2.md`
