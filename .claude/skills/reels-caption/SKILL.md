# reels-caption — 캡션

먼저 읽기: `../account-identity/SKILL.md`, `../account-identity/references/rules.md`, 협찬이면 `../account-identity/references/brands.md`

## 입력
- 가게 정보(위치·영업시간은 출처·연도 포함), 직접 경험 메모(먹은 메뉴), 확정 커버, 협찬 가이드(있으면)

## 형식 2가지
| 형식 | 언제 | 본문 |
|---|---|---|
| **짧은 반말형(기본)** | 항상 기본 | 반말 혼잣말 5~8줄, 줄당 30자 이내, 단락 없이 줄바꿈 |
| 정보형 | 협찬 가이드가 정보 전달을 요구하거나 동연이 요청 | 존댓말 구어체 4단락, 250~350자 |

기본형 근거: 히트작 미동식당 캡션(짧은 반말 7줄, 공유 4,547). 예:
"충정로 직장인들 다 알고 있었던 보물섬 / 나는 이제 알아버렸어••• / 1인 만원 안주 오마카세인데 … / 여기 진짜 한번만 가본사람은 없을걸...?"

## 구조
1. (협찬) 광고 표기 줄: 기본 "[광고]", 업체 지정 우선(예: 교토오니마루 "#협찬" 맨 첫 줄)
2. **첫 줄 훅**: 반말 혼잣말 25자 이하. 커버와 같은 킬러 소재를 다른 말로. 정보격차·소환형 권장("○○ 좋아하는 사람 여기,,")
3. 본문
   - 짧은 반말형: 킬러 소재 근거 → 직접 먹은 것(동연 표현 그대로) → 공간·디테일 한 줄 → 소환·재방문 마무리. 가게명 #해시태그 한 번
   - 정보형: ① 어디·무엇 ② 킬러 소재 근거 ③ 직접 먹은 것·경험 ④ 실용 팁 또는 소환 마무리
   - 업체 소개 문구는 1줄까지만(광고 냄새 방지)
4. 협찬 필수 블록(이벤트 등): 가이드 원문 그대로
5. 정보 블록: 📍상호 ⏰영업시간 🚨휴무 — 확인된 것만. 모르면 줄을 빼고 [확인 필요]로 보고
6. 해시태그: 지역 3 + 음식 3 + 광역 2. 협찬 필수 태그는 맨 아래 별도 줄

## 자가검증 (출력 뒤에 표로)
| 항목 | 결과 |
|---|---|
| 형식과 분량(짧은 반말형 5~8줄·줄당 30자 / 정보형 250~350자) | |
| 첫 줄 반말·25자 이하 | |
| 업체 소개 문구 1줄 이하 | |
| 금지어·근거 없는 평가 | `python3 scripts/lint_copy.py` 결과 |
| 숫자 출처 | 입력에 있는 숫자만 |
| 안 먹은 메뉴 평가 | 없음 / [확인 필요] 표시 |
| 이모지(본문 1개 이하) | |

글자 수는 직접 세지 말고 `python3 -c "print(len(open('파일').read()))"` 등으로 잰다.
