# reels-cover-title — 커버 3안

먼저 읽기: `../account-identity/SKILL.md`, `../account-identity/references/rules.md`, 협찬이면 `../account-identity/references/brands.md`

## 입력
- 필수: 가게 정보(지역, 업종, 메뉴·가격·특이 룰 중 확인된 것), 협찬 여부
- 있으면: 사진 설명(무엇이 보이는지), 직접 경험 메모, 같은 가게를 다룬 다른 계정 커버(검색 상위)
- 사진 설명이 없으면 사진과 맞지 않을 수 있는 표현마다 [확인 필요: 사진 일치]

## 절차
0. **질문 게이트 (문구 만들기 전에 반드시)**: 아래 3개 중 입력에서 확인된 것이 있는지 본다.
   - ① 가격·양: 주변 대비 싸거나 많은가, 가격 숫자가 있나
   - ② 희소성: 품절 시간, 웨이팅, 한정·기간, 새로 오픈·재오픈
   - ③ 이 집만의 것: 다른 데서 보기 힘든 메뉴·룰·공간·사람 이야기
   - 하나도 없으면 출력 맨 위에 **"⚠️ 킬러 소재 약함"**과 3개 질문을 내고 **멈춘다**. 동연이 "그냥 진행"이라고 하면 3안을 "임시"로 표시해서 낸다.
   - 단, reels-auto에서 실행될 때는 멈추지 않고 경고만 띄운 뒤 진행한다(질문은 맨 끝).
   - 업체 소개 문구(슬로건)만으로는 킬러 소재로 인정하지 않는다.
1. **킬러 소재 찾기**: 입력에서 "기준점 대비 반전"을 1~3개 뽑는다.
   - 가격(만원 오마카세), 구성(이 버섯까지 나오는), 귀환·오픈(돌아왔다 ○○), 비유(○○계 끝판왕), 정보격차(직장인들 다 알던)
   - 없으면 "킬러 소재 없음"이라고 쓰고, 동연에게 확인할 질문 1개를 낸다(예: "가격이나 특이한 룰 있어?").
2. **레퍼런스·이미 쓰인 훅**: `python3 scripts/hookbank.py query <업종 키워드>`로 같은 업종 상위 영상의 형식을 참고한다. 같은 가게 다른 계정 커버가 있으면 같은 훅 유형·단어를 피한다(예: 미면정 "하얀공의 정체" ×3).
3. **3안 작성**: 각 안은 서로 다른 유형(가격·룰 / 구성놀람 / 신상·소식 / 비유·최상급 / 정보격차 / 공간반전 중).
   - 형식: 큰 1줄 / 큰 2줄 / 작은 줄(선택). 큰 줄은 줄당 공백 제외 6~12자 권장.
   - 반말. 상호는 넣지 않는다(상호 자체가 뉴스일 때만 예외).
4. **자가검증**(안마다 표로): 킬러 소재가 커버에 있나 / 금지 단독 평가어 없나 / 숫자가 입력에 있나 / 사진과 맞나 / 협찬 냄새 없나
   - **소환 테스트**: "이 커버 보고 ○○한 친구한테 △△라서 보낸다"를 한 문장으로 쓴다. ○○·△△가 구체적이지 않으면(예: "빵 좋아하는 친구") 탈락.
   - **답 검사**: 질문형 커버면 영상 속 답이 시청자 이득(가격·팁·놀람)인지 본다. 답이 업체 슬로건이면 탈락.
5. **추천 1개 + 이유 2줄**: 내 히트 커버(아래)와 어떤 점이 같은지로 설명한다. 탈락하지 않은 안이 없으면 추천 대신 게이트 질문으로 돌아간다.
6. (선택) 체험용 릴스(비팔로워에게 먼저 노출) 사용 가능하면 상위 2안을 각각 올려 비교하자고 제안한다. 계정·협찬 게시물 사용 가능 여부는 확인 필요.

## 출력 형식
```
### 커버 3안
| 안 | 큰 1줄 | 큰 2줄 | 작은 줄 | 유형 |
### 자가검증
| 안 | 킬러 소재 | 금지어 | 숫자 출처 | 사진 일치 | 광고 냄새 | 소환 테스트 문장 | 답 검사 |
### 추천: ○안
이유 2줄
### 확인 필요
- ...
```
