# 업체별 규칙

```
## 업체명
- 근거: (가이드 원문 / 게시 캡션 shortcode, 날짜)
- 광고 표기 위치:
- 필수 문구(그대로):
- 필수 해시태그:
- 금지 표현:
- 위치 지정:
- 기타:
```
